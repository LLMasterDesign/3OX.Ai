Operationally, R expands to the PHENO chain plus Warden gate:

// R(λ, τ) ≔ unique_bind(λ) fn R(λ) → τ { intent = normalize(λ) // Encode.Intent route = resolve_slot(intent) // ROUTE_DETERMINISM warden.gate(route, λ) // WARDEN_FIRST τ = emit_typed(route) // PHENO τ · RECEIPT_COLLAPSE assert |candidates| == 1 // ∃! return τ }

04

How 3OX enforces ∃!

Warden · 12 laws · fail-closed

The unique-existence quantifier is not philosophical. It is compiled into Warden field laws in .3ox/(3)Rules/limits.toml. These are the teeth of Λᴳ that make R functional:

SLOT_IDENTITY
One slot = one function identity. Files are faces of a slot, not rival identities. Prevents λ from splitting into multiple τ owners.
ROUTE_DETERMINISM
Same intent + same state → same route. Ambiguous resolution halts. This is ∃! at the router.
DECLARED_CAPABILITY
No declaration → no permission. Undeclared tools cannot invent alternate τ paths.
WARDEN_FIRST
Mutation passes Warden before execution. R is evaluated before side effects — never after.
RECEIPT_COLLAPSE
Every outcome collapses to a receipt. Success, deny, and error are all members of T — still unique.
FAIL_CLOSED
If Warden cannot decide, deny. Uncertainty maps to a typed deny τ, preserving total coverage of Λᴳ.
MIGRATION_SEAL
PHENO meaning cannot silently change. Λᴳ is sealed; extending the lattice requires an explicit migration Ω.

EXC surface law reinforces uniqueness at the boundary identity layer: 1 EXC identity = 1 .exc + 1 .kdl + 1 .exs — not a weighted triple. If KDL or exs diverges, EXC wins. One meaning, one τ family.
