# 3OX.Ai — Deployment Readiness Audit

**Last scan:** 26.03.13 · **Use this before going live.**

---

## ✅ READY — Works Today

| Component | Platform | How to Run |
|-----------|----------|------------|
| **3OX.BUILDER** | Linux, macOS, WSL | `cd 3OX.BUILDER` → `make build` → `make install-cli` |
| **VSO Agent** | Any (Ruby 3.2+, Rust) | `cd "3OX Agents/VSO Agent"` → `ruby .3ox/run.rb` |
| **Root station** | Linux, macOS | `ruby .3ox/run.rb start` (supervisor) or `ruby .3ox/run.rb teleprompt` |
| **3ox.store landing** | VPS + nginx | `bash 1n3ox-temp/sync-3ox-store.sh` → serve `/var/www/3ox.store` |
| **systemd units** | Linux (VPS) | `_TRON/systemd/*.service` — copy to `/etc/systemd/system/` |

## ⚠️ DEPENDS ON EXTERNAL

| Component | Dependency | Where It Lives |
|-----------|------------|----------------|
| **TelePromptR** | Separate repo/codebase | `/root/!CMD.VPS/TelePromptR` on VPS |
| **speaker-mesh** | Inside TelePromptR | `tools/speaker_mesh.rb` |
| **teleprompter.rb** | Inside TelePromptR | `3ox.station/vec3/bin/teleprompter.rb` |
| **merge.sh** | Generated by Money.Bagz teleprompt | `!0UT.BUDGET/tpr/merge.sh` (created on first teleprompt run) |

**Implication:** Full Telegram routing requires TelePromptR deployed on VPS. 3OX.Ai repo syncs agent configs into it.

## 📋 PRE-FLIGHT CHECKLIST (Before Tonight)

### 1. Clone and verify
```bash

cd 3OX.Ai
```

### 2. Test root station (no VPS)
```bash
ruby .3ox/run.rb status
ruby .3ox/run.rb teleprompt   # May show fallback if scripts missing — OK
```

### 3. Test 3OX.BUILDER
```bash
cd 3OX.BUILDER
make build
make install-cli
3ox help
```

### 4. Test VSO Agent
```bash
cd "3OX Agents/VSO Agent"
ruby .3ox/run.rb
```

### 5. Test Money.Bagz (local)
